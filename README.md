  <h1>Chisel Game Engine</h1>
</div>

Chisel is an open-source - but not open contribution - 3D engine for making games in a similar workflow to those of the 2000's. This repository hosts the core engine and tool code for Chisel, which is used by the standard SDK, and can be used for reference or forking for your own version to use [with the SDK](https://chiselengine.com/download).


On its own, this repository has only a very minimal template game. If you wish to use Chisel for your own development, it's recommended to [download the SDK](https://chiselengine.com/download); which includes a full FPS template, and a typical project setup for using Chisel to make games independently or in a team setting. You are free to modify, use, and share Chisel in whatever way you wish!

This repo also acts as a general bug-report hub for the default SDK and the engine itself.
